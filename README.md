# 3D 打印零件助手

3D 打印零件助手 0.9.0 开发版是一款面向 Blender 4.5 LTS 的中文辅助建模插件。当前首个正式
零件是四孔矩形转接板：用户可以直接填写毫米尺寸，也可以先用自然语言描述用途，让自己配置的
AI 判断缺少哪些测量并形成参数候选。候选必须经过本地检查和用户确认，随后才由事务创建真实
网格，并从实际网格验证尺寸、圆角、贯穿孔、流形和既有场景保护。

安装后，3D 视图右下角仍有用户指定的 92 × 92 像素小助手；点击它会直接打开新的转接板流程。
原“场景领航员”AI 摆放功能没有删除，仍保留在 `N → BSA` 的默认折叠面板中。没有 API 时，
0.9.0 仍可直接填写尺寸并完成全部本地建模；只有用户主动选择“整理需求”、检查发送数据并同意
后，插件才会调用用户自己的 OpenAI-compatible 服务。

0.6.2 增加 LM Studio 结构化输出适配，已用本机 `qwen/qwen3-4b-2507` 在 Blender 4.5.12 跑通真实规划和确认执行。提示词澄清后，一轮固定任务通过 20/20，其中真正调用模型的正向任务为 8/8；先前一轮为 18/20，两个矛盾约束被回滚。保留两轮结果，不能据此宣称任意指令都可靠。详见 [本版中文测试报告](docs/RELEASE_0.6.2_TEST_REPORT.md)。

0.6.1 新增本地生成的实际动作清单、AI 解锁保护，以及 20 个固定任务的独立评测。模型摘要只供参考，不能替代确认清单。符合动作协议并不等于符合用户意图，请逐项检查对象、方向、距离和保护约束。

0.6.0 第一次打通了 AI 结构化规划：本地解析器能可靠理解的指令完全离线处理；其他指令先展示本轮将发送的数据，用户点击“同意并调用 AI”后才访问自己配置的 OpenAI-compatible 服务。模型只能提出白名单动作，不能执行 Python，也不能直接修改 Blender。

仓库另有一条尚未进入正式插件 UI 的“参数化电路板外壳”实验轨。P0 已完成毫米制参数推导和
FDM 最小规则检查；P1 已在 Blender 4.5.12 中事务化创建装配预览并验证失败回滚。它目前不是
可直接打印的最终网格，准确范围见 [P1 中文说明](docs/PARAMETRIC_ENCLOSURE_P1.md)和
[P1 开发者测试报告](docs/PARAMETRIC_ENCLOSURE_P1_TEST_REPORT.md)。

产品方向是“3D 打印零件助手”：0.9.0 在首个创建闭环上继续打通“创建后描述修改
→ 只读差异 → 用户确认 → 事务更新 → 一步撤销”。AI 复用用户自带 API 设置，只能产生
受限参数补丁，不能直接执行 Python 或修改 Blender。完整边界见
[3D 打印零件助手方案 V0.1](docs/3D_PRINT_PART_ASSISTANT_PLAN_V0.1.md)。

矩形转接板 P0 参数核心、P1 Blender 真实网格、P2 本地界面、P3 AI 需求入口和 P4 连续修改现已完成：可以
从安装后的插件描述需求、补充测量、检查候选，也可以直接填写尺寸；确认后创建单一封闭板件和
真实贯穿孔，失败时回滚。准确范围和操作方法见
[矩形转接板 P0 中文说明](docs/ADAPTER_PLATE_P0.md)和
[矩形转接板 P1 中文说明](docs/ADAPTER_PLATE_P1.md)、
[矩形转接板 P2 中文说明](docs/ADAPTER_PLATE_P2.md)和
[P3 AI 需求闭环说明](docs/PRINT_INTENT_P3.md)和
[P4 连续修改说明](docs/ADAPTER_PLATE_P4.md)。本版完整测试证据见
[0.9.0 中文验收报告](docs/RELEASE_0.9.0_TEST_REPORT.md)。

## 安装后会看到什么

1. 3D 视图右下角出现小助手。它只是界面入口，不是场景物体，不会进入渲染或导出。
2. 点击助手打开“3D 打印零件”；也可以按 `N`，从 `BSA → 3D 打印零件`进入。
3. 描述用途和已知尺寸，点击“整理需求”；如果没有 API，选择“我已知道尺寸，直接填写”。
4. 使用 AI 时，先检查本轮发送内容并明确同意。缺少关键尺寸时，界面会说明要测量什么、为什么。
5. AI 候选会转换成可编辑毫米参数，并再次经过本地几何检查；也可以直接手工填写这些参数。
6. 阅读摘要后点击“确认并创建”。只有此时事务执行层才创建真实网格。
7. 界面显示实际网格验证结果；成功后可继续输入“板加宽 10 毫米，右边不动”一类修改。
8. 修改前会显示尺寸差异、固定边和孔位保持结果；确认后替换真实网格，失败回滚，成功后可一步撤销。

默认示例是 80 × 40 × 3 mm、2 mm 圆角、四个真实贯穿孔。它不需要现成物体；直接填写尺寸也
不需要 API。

## 安装方法

本机构建后的安装包为 `dist/blender_scene_assistant-0.9.0.zip`。构建产物不放入源码历史；GitHub
Release 发布前，仓库发布页可能仍只有旧版。请不要把 GitHub 自动生成的“Source code”压缩包
当作插件安装包。

在 Blender 4.5 中打开“编辑 → 偏好设置 → 获取扩展”，从右上角菜单选择“从磁盘安装”，选中
ZIP 并启用。若已安装旧版，请安装 0.9.0 包并重启 Blender。

测试转接板不需要现成物体，新建空白 Blender 工程即可。以下指令只用于仍保留的旧“场景领航员”
面板；如要测试该旧功能，可以打开 `tests/fixtures/desk_lamp_demo.blend`：

- `把 Lamp 放到 Desk 右侧，并锁定 Desk`：本地生成计划。
- `Lamp 向左移动 20 厘米`：本地生成定距移动计划。
- `解除锁定 Desk`：本地生成解锁计划。
- `重新安排 Lamp 和 Desk，让画面更紧凑`：进入 AI 数据确认流程。

每次都先检查计划，再点击“确认并执行”。也可从“设置 → 精确控制”手动选择物体、目标和摆放区域。

## 使用自己的 API

0.9.0 的“3D 打印零件”流程可以调用 AI，也可以完全离线使用。插件与旧“场景领航员”复用同一
套会话级 AI 设置；右下角小助手打开打印件主流程。

1. 点击视图右下角助手，或从 `N → BSA → 3D 打印零件`打开面板。
2. 展开“AI 服务设置”。
3. 填写 OpenAI-compatible API 地址；远程地址必须使用 HTTPS，本机服务可以使用 `http://127.0.0.1` 或 `http://localhost`。
4. 填写模型名和临时 API Key。Key 只保留在当前 Blender 会话，也可通过 `BSA_API_KEY` 或 `OPENAI_API_KEY` 环境变量提供。
5. 点击“测试连接”，检查地址、认证和模型是否可用。
6. 输入零件用途和已知尺寸，点击“整理需求”。
7. 检查本轮实际发送内容；只有点击“同意并调用 AI”后才真正发送。
8. 根据提示补充测量，或核对 AI 转换出的毫米参数，再点击“确认并创建”。

如果提示“Blender 当前禁止扩展联网”，请到“编辑 → 偏好设置 → 系统”启用“允许联网访问”。不同兼容服务对 `/models`、`/chat/completions` 和 JSON 输出的支持并不完全相同；连接测试成功不保证所选模型一定能生成合格计划。

### 本机 LM Studio 的填写示例

先在 LM Studio 加载聊天模型并启动本地服务器，再打开插件的“设置 → AI 服务”：

| 设置 | 本机已实测的值 |
|---|---|
| API 地址 | `http://127.0.0.1:1234/v1` |
| 模型 | `qwen/qwen3-4b-2507`（以本机列表为准） |
| 输出格式 | `LM Studio 结构化输出` |
| API Key | 服务未启用认证时留空；若设置过 Key 环境变量，也需清除它们 |

同一台电脑优先填 `127.0.0.1`，不要照抄截图中的 `172.25.96.1`；插件拒绝非回环地址的明文 HTTP。输出格式默认仍是“通用 JSON”，不会自动切换或自动降级。旧版本在当前 LM Studio 上会因 `json_object` 不兼容而返回 HTTP 400。

`qwen3-vl-4b-instruct` 已做单独安装版测试：地址和模型可以连接，但它没有生成插件要求的严格结构化计划，因此旧场景功能暂不把它列为推荐模型。测试被安全拦截，场景没有改变。当前请使用上表中的 `qwen/qwen3-4b-2507`；不需要云端 API Key。

打开演示场景后输入：`让 Lamp 落在 Desk 顶面的右侧，Desk 保持原样`。点击“生成计划”，检查发送数据，再点“同意发送并生成计划”；核对实际动作后点“确认并执行”。这是已实测的 AI 路径。明确的 `把 Lamp 放到 Desk 右侧` 走本地解析，不会调用模型。

## 当前已经完成

- 可点击、可隐藏的二维助手入口；点击后进入新的 3D 打印零件主流程。
- 矩形转接板自然语言入口：发送前确认、AI 缺失测量追问、用户补充和严格设计候选。
- AI 候选无损转换为毫米参数表单，并再次经过本地结构与几何检查；不支持结构明确拒绝。
- 矩形转接板参数面板：毫米制板件尺寸、两组双孔、渐进展开、本地检查和明确确认。
- 确认后创建一个带真实贯穿孔的单一封闭流形网格，并显示独立验证结果。
- 创建后可继续用自然语言或精确尺寸修改板宽/板深，保持全部孔的世界位置和孔径。
- 修改经过差异确认、独立更新事务、实际网格回读和失败回滚；成功后可一步撤销。
- 输入变化使旧摘要失效；重复零件编号、孔越界、孔重叠和无效尺寸均在创建前拒绝。
- 本地解析明确的摆放、定距移动、锁定和解除锁定指令。
- AI 调用前的数据预览和逐次用户同意，不会静默上传场景。
- 最多 20 个相关可见对象的最小上下文构建与稳定筛选。
- OpenAI-compatible 结构化规划、一次 JSON 修复机会和用量显示。
- 严格候选计划协议；拒绝未知字段、未知动作、错误对象和危险参数。
- 模型不能提供可信场景指纹、确认标志或任意 Python；这些信息由本地主进程生成。
- 场景指纹、过期结果拒绝、事务执行、失败回滚和结果验证。
- 会话级 API Key、HTTPS 限制、联网权限、超时、取消和隔离网络子进程。
- Key 不写入 `.blend`、命令行或日志；模型失败、取消和超时都不会修改场景。
- 纯 Python 测试、Blender 4.5 后台集成测试、隔离安装测试和 20 次重复验证。
- 实验轨可从严格毫米参数创建 12 部件电路板外壳装配预览；创建需要确认，尺寸不一致会完整回滚。
- AI 候选协议只能请求测量、提出受支持零件族设计或生成受限参数补丁；三类候选都已接入
  3D 打印界面，但参数补丁目前只能改转接板的宽度和深度。

## 当前不能做什么

0.9.0 的 3D 打印流程只支持矩形转接板和两组固定语义双孔。它还不能创建任意形状，不能添加
沉孔、螺纹、加强筋或复杂曲面。创建后修改目前只支持板宽和板深，不支持厚度、孔径、孔距和孔数；
也没有尺寸标注、STL/3MF 导出和切片器联动。
它只验证 Blender 网格，没有真实打印和试装证据。

保留的旧场景功能只允许 AI 使用已经验证过的 `place_on`、`move` 和 `lock` 动作。AI 不能自行解锁；需要先用本地明确指令 `解除锁定 Desk` 并确认。它不会修改材质、灯光或相机，也还不能完成真正的多物体构图、环形排列、对齐和分布。

仓库中的外壳 P1 只能由开发测试入口生成装配预览，
还没有参数面板、自然语言入口、布尔开孔、螺丝孔、流形检查或导出，不能作为“AI 已经会建模”
的证据。

矩形转接板现在可以从正式参数界面创建，但仍没有尺寸标注、导出、切片或打印证据，不能把
“网格验证通过”描述成“已经验证可打印”。

自然语言理解范围变大了，但执行能力仍受白名单限制。“做成高级感”之类要求如果无法映射到现有动作，会得到明确错误，而不是让模型自由控制 Blender。表面摆放仍只支持能用水平世界坐标边界框可靠表达的支撑面。
