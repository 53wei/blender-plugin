# 3D 打印零件助手 P3：自然语言需求到可确认模型

日期：2026-10-18  
对应版本：0.8.0  
状态：已在 Blender 4.5.12 中实现开发者测试闭环

## 用户现在可以完成什么

安装插件后，点击右下角小助手，或打开 `N → BSA → 3D 打印零件`：

1. 用中文描述用途、安装对象和已经知道的尺寸；
2. 检查本轮实际会发送的数据，并明确同意调用自己的 AI 服务；
3. 如果尺寸不足，查看需要测量什么以及原因，填写补充信息后再次确认发送；
4. AI 返回四孔矩形转接板候选后，插件把它转换为可编辑毫米参数；
5. 本地重新检查外形、孔位、孔径、重叠和圆角；
6. 用户核对摘要并点击“确认并创建”；
7. 事务生成真实贯穿孔网格，再从 Blender 实际网格验证结果。

没有 API 时，选择“我已知道尺寸，直接填写”，仍可完整使用 0.7.0 的本地创建流程。

## AI 与 Blender 的边界

AI 不直接操控 Blender。它只能返回三种关闭字段候选：缺失测量、设计候选或参数补丁。P3 界面
只执行前两种流程；参数补丁虽然可以被解析和本地计算，但创建后的 Blender 网格修改事务尚未
实现，因此会明确提示暂不支持。

设计候选必须是当前能够无损表达的结构：`device` 两孔沿 X 轴，`support` 两孔沿 Y 轴，两孔
各自同径。斜向孔、未知安装模式、任意孔数、沉孔、螺纹和复杂外形不会被近似成一个“看起来
差不多”的模型。

## 每轮会发送什么

- 当前用户需求；
- 上一轮已经展示的缺失测量问题；
- 用户当前填写的补充答案；
- 严格候选 JSON Schema。

不会发送 Blender 场景、网格、图片、历史项目、界面默认尺寸或 API Key。第一次候选无效时最多
修复一次。任何网络、格式、结构或几何失败都不会修改场景。

## 仍未达到的最终产品能力

- 不能根据照片恢复精确毫米尺寸，也没有图片上传入口；
- 不能支持矩形转接板之外的任意零件；
- 不能在创建后用自然语言安全修改现有网格；
- 没有尺寸标注、STL/3MF 导出、切片器联动或真实打印记录；
- 没有真实外部用户验证，也没有证明所有兼容模型都能稳定输出候选。

因此 0.8.0 是第一个真实 AI 辅助建模竖向闭环，不是最终完整产品。
