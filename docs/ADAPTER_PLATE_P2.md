# 矩形转接板 P2：正式本地创建界面

日期：2026-10-18  
对应版本：0.7.0  
状态：已在 Blender 4.5.12 中实现并通过开发者验收

## 安装后是什么效果

安装并启用插件后，用户有两个入口：

1. 点击 3D 视图右下角的小助手；
2. 把鼠标放在 3D 视图，按 `N`，打开 `BSA → 3D 打印零件`。

两个入口都会进入同一套矩形转接板流程。首屏只显示零件编号、板宽、板深、厚度、圆角和一个
“检查参数”按钮。四个孔的详细位置默认折叠；需要修改时展开“孔位参数”。

操作顺序固定为：

1. **填写参数**：单位全部是毫米。设备孔组是沿 X 轴排列的一对孔，支架孔组是沿 Y 轴排列的
   一对孔。
2. **检查设计**：本地展开四个实际孔中心，检查孔是否超出外形、互相重叠或落入圆角禁区。
   这一步不联网，也不修改场景。
3. **确认并创建**：只有用户确认后，才通过 `AdapterPlateCreationService` 开始创建。
4. **查看结果**：界面明确显示实际网格验证是否通过。失败会恢复创建前场景，成功后可继续创建
   下一块板。

默认示例会生成 80 × 40 × 3 mm、2 mm 圆角的单一封闭网格，包含两组共四个真实贯穿孔。

## 为什么不是“一按就猜出用户想要的模型”

当前版本不猜。它只支持一个已经定义、能测试、能验证的零件族。用户给出明确毫米参数，软件先
生成可读摘要，再由用户确认。以后接入 AI 时，AI 也只能填写同一严格参数候选；它不能执行任意
Python，不能绕过本地几何检查，也不能跳过确认。

## 界面设计原则

- 每个阶段只有一个主要按钮；输入、确认和结果不会同时堆在一个长面板中。
- 复杂孔位参数渐进展开，默认首屏保持短小。
- 所有输入都有可见中文标签，不用占位文字代替字段名。
- 错误说明包含原因和恢复方式；成功状态不会静默。
- 原“场景领航员”保留为折叠的旧功能，右下角助手改为打开 3D 打印零件主流程。

## 已验证范围

- 140 项纯 Python 测试通过；其中 5 项是本界面表单到严格计划的专项测试。
- Blender 4.5.12 后台实际注册面板，证明检查阶段不创建物体、参数变化使旧摘要失效、确认后
  创建一件四孔封闭流形网格。
- 既有场景 UI、AI 数据确认、摆放事务和转接板 P1 网格回归继续通过。
- 真实窗口检查覆盖输入页和确认页；未发起网络请求，也未保存测试场景。

## 当前边界

- 只支持矩形转接板、圆角和两组双圆孔；没有任意孔列表、沉孔、螺纹、加强筋或复杂曲面。
- 尚未实现创建后参数化修改、尺寸标注、STL/3MF 导出和切片器联动。
- 尚未完成材料、打印方向、最小壁厚、收缩补偿和打印机配置门禁。
- 尚无真实打印和试装数据，所以“网格验证通过”不等于“实物可打印并装配成功”。
- 3D 打印流程尚未接 AI；当前不需要 API。旧场景摆放功能仍可配置用户自己的 API。
