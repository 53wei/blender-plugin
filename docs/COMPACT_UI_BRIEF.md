# 简洁助手界面约定

范围：Blender 4.5 原生工作界面，用户已经确认；只改变呈现及头像。不是网页，也不是完整建模功能。

## 界面方向约定（Direction contract）

- 核心：让用户在几秒内知道下一步按什么，去掉“聊天框、控制台、配置面板全展开”的结构。
- 原生表达：沿用用户的 Blender 主题与内置字体；主按钮使用原生强调，正文左对齐，不加入卡片套卡片、炫光或自动动画。角色本身是唯一可爱视觉元素。
- 使用顺序：输入明确要求；需要 AI 时先检查数据并同意发送；检查实际动作；确认执行；查看验证或明确失败原因。
- 首屏：一行阶段标题，右侧设置入口；标注“你想怎么调整”的输入框；一个主按钮；一条对象名称/离线示例。默认无大头像、对话历史、用量列表或手动表单。
- 形式：用户明确选择的简洁方案，无随机概念流程。继承原生控件，不另外设计平台外壳。头像 92 像素、点击半径 42 像素；浮窗宽度缩小，不放大助手。
- 完成条件：未经检查和记录不算完成；检查窄侧栏、浮窗和关键状态，记录结论及图片来源，保留未验证事项。

设置展开后仍能访问 AI 连接、精确控制、助手显示开关和调用用量。实际动作清单不折叠；完整发送详情有明确入口。错误仅出现一处并给恢复办法。表面摆放、移动、锁定仍是现有能力，不因文案变得更像 AI 就扩充执行权限。
