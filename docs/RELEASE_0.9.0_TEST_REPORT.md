本报告不把任意零件、图片理解、厚度/孔参数修改、STL/3MF 导出、切片或真实打印列为已完成能力。

## 关键行为证据

- 默认设计创建为 80 × 40 × 3 mm、四个真实贯穿孔和单一封闭流形。
- “宽度改为 90 mm，右边保持不动”产生 90 × 40 × 3 mm 设计，模型 X 原点补偿为 -10 mm。
- 更新前后四个孔的世界中心和孔径一致。
- 修改目标外的参考立方体世界变换完全不变。
- 验证器故意读到错误孔径时，事务返回 `ROLLED_BACK` 并验证旧状态已恢复。
- “撤销本次修改”使用反向更新事务，恢复 80 × 40 × 3 mm 和原始孔位。

## 网络与信任边界

- AI 修改请求在联网前展示，用户不同意就不发送；
- 只增加当前插件管理设计的参数 JSON，不发送网格、其他对象、图片或 API Key；
- AI 只能提出 `parameter_patch`，本地程序重建、验证和生成差异；
- UI 不直接修改网格，Blender 状态变化经过更新事务与执行端口；
- 计划过期、元数据不完整、实际网格不一致或不支持结构均闭合失败。

## 尚存风险

1. AI 闭环使用本机可控 OpenAI-compatible 模拟服务，验证了真实 HTTP、子进程和严格输出，但不代表所有模型都能稳定生成合格补丁。
2. 连续修改只支持本版插件创建、元数据完整且未被手工改坏的矩形转接板。
3. 当前只能改板宽和板深；厚度、圆角和所有孔参数会被强制保持。
4. 只保存上一版设计，没有无限历史或分支版本。
5. 尚无照片尺寸恢复、尺寸标注、STL/3MF 导出、切片器联动和真实打印试装证据。
6. 本机未安装 Ruff，因此 Ruff 检查未执行；`compileall`、161 项测试、Blender 集成和安装版回归均已通过。

结论：0.9.0 已从“一次生成”推进到“生成后可安全继续调整”，但仍是单一零件族的开发者验证版，不得宣称任意建模或已验证可打印。
