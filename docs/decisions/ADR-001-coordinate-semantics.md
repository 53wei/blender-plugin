# ADR 001 坐标语义

状态：已接受

日期：2026-09-10

## 背景

相对摆放必须先冻结一个稳定语义，规划器和界面才能得到可重复测试。直接推断物体局部朝向，会让相同计划因导入资产的轴向差异产生不同结果，并把歧义隐藏在规划器内部。

## 决策

M1 使用 Blender 世界坐标。右侧为正 X，左侧为负 X，前侧为负 Y，后侧为正 Y。`place_on` 使用目标物体世界坐标 AABB 的顶部表面。目标物体绕世界 X 或 Y 明显旋转时，返回不支持的几何错误。

## 备选方案

M1 不采用目标局部坐标，因为不同来源资产的前向轴不一致。也不采用相机相对坐标，因为视口变化会导致相同计划产生不同结果。

## 影响

该语义容易解释和测试，但部分美术资产需要先手工调整朝向。只有基准测试证明 AABB 不够用后，才通过新 ADR 引入 OBB 或射线检测。

## 验证

纯 Python 与 Blender headless 测试验证左右摆放、表面间隙、过期计划拒绝、锁定保护和重复执行一致性。
