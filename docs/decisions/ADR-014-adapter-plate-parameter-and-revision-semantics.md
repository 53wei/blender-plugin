# ADR-014：矩形转接板参数与保孔位修改语义

- 状态：已接受
- 日期：2026-10-18
- 决策阶段：3D 打印零件助手 P0

## 背景

首个完整用例是“现有设备和支架孔位不一致，生成一块转接板”。这个用例只有在孔位、板尺寸和
后续修改的含义固定后，才能安全接入 AI、Blender 和打印检查。尤其是“板加长 10 毫米，设备
安装孔保持不变”不能被解释成任意网格缩放，否则孔径和孔距都会被破坏。

## 决策

1. P0 只支持轴对齐的矩形平板、圆形贯穿孔和可选外轮廓圆角。暂不支持沉头孔、螺纹、长圆孔、
   台阶、加强筋、任意曲面或照片反推尺寸；这些请求必须返回明确的不支持错误。
2. 所有长度单位为毫米。板的局部原点位于左前下角，`+X` 为宽度，`+Y` 为深度，`+Z` 为厚度。
3. 安装孔按“安装模式”组织。每个模式保存一个局部原点，每个孔保存相对该原点的偏移和直径，
   便于表达设备孔组和支架孔组，而不是把所有孔降级成互不相关的点。
4. P0 的改尺寸操作必须显式指定 X/Y 固定边，并显式列出要保持世界位置不变的全部安装模式。
   本阶段只支持“所有模式都保持不变”；只保持部分模式的请求返回
   `SPATIAL_UNSUPPORTED_GEOMETRY`，避免未定义的剩余孔组行为。
5. 从左边或前边加长时，孔的板内局部坐标不变；从右边或后边加长时，孔的局部坐标随新增长度
   平移，板对象反向平移；以中心加长时各移动一半。这样孔的世界坐标保持不变。
6. 每次修改后重新检查：数值有限且为正、ID 唯一、圆角可行、孔完整落在轮廓内、孔之间不重叠。
   不允许为了生成成功而静默夹值、缩孔或移动孔。
7. AI 只可产生 `needs_input`、`design_candidate` 或 `parameter_patch` 三种关闭字段候选；本地解析、
   参数模型和验证通过后才可进入后续确认。P0 不增加网络调用、Blender UI 或网格执行器。

## 结果

- 同一输入得到稳定的参数结果，后续 Blender 执行器可以消费明确规格，而不是模型生成的脚本。
- “加长但孔位不变”具有可测试的几何含义，并能在尺寸不足时明确失败。
- P0 暂时不能表达只固定设备孔、让支架孔跟随某一边移动；需要真实用例后再用新 ADR 扩展。

## 未采用方案

- **直接缩放网格**：会同时改变孔径和孔距，破坏装配关系。
- **允许 AI 返回任意参数字典**：无法封闭字段，也无法验证未识别几何。
- **仅用图片估算孔位**：不能提供可靠的毫米级配合尺寸。
- **一次支持所有紧固结构**：会把首个可验证用例扩成通用 CAD，无法形成可信验收线。

## 验证

- 纯 Python 测试覆盖转接板确定性生成、非法数值、越界孔、重叠孔和圆角区域。
- 修改测试覆盖左/右/中心及前/后固定边，并证明修改前后孔的世界坐标一致。
- 候选协议测试覆盖三种状态、关闭字段、可信字段注入、未知零件族和任意 Python 拒绝。
