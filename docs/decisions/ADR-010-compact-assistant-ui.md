# ADR 010 简洁助手界面与本地头像替换

状态：已接受；日期：2026-10-12。

## 背景

用户提供截图指出主界面过长、杂乱、不知道如何操作，并明确确认简洁方案：主面板仅突出输入、当前阶段和一个主要动作；AI 连接、精确控制和用量收进设置。用户指定第三张角色图替换旧机器人，屏幕占用不能变大。

## 决策

在现有 M2 范围内重整呈现，不新增场景动作。保留 Blender 原生主题、控件、键盘操作和 N → BSA 备用入口。取消大幅面板头像、重复对话、重复结果说明；每个阶段只突出下一步。AI 数据审查与确认执行仍是两个独立步骤，完整发送详情可展开，实际动作和保护约束不得被隐藏。

设置默认在会话中收起，旧项目保存的“展开精确控制”不能撑开主界面。缺少模型时显示明确的设置入口，不让用户盲按后得到笼统报错。文本按中文显示宽度和实际面板宽度换行。

独立审查发现精简时遗漏了连接测试返回的模型名称；恢复为设置中的“可用模型名称”折叠项，最多显示已有连接层保存的 8 个名称。展开状态仅在当前会话保留，不触发联网，不改变请求协议。

头像绘制保持 92 × 92 像素，点击半径保持 42 像素，位置不变；仅替换图像并减少悬停装饰。用户图片经内置图像编辑工具处理为透明头像，不把它宣称为原创或已获公开分发授权。本版只在本地构建和验收，不自动提交、推送或公开发布。

2026-10-16 补充：用户明确确认拥有该角色图的使用权，并要求将本版推送到公开 GitHub 仓库。项目不把图片宣称为原创，继续保留来源、编辑提示和未单列图片许可证文本的事实。

## 未采用

- 不制作独立网页或重型自绘聊天客户端，避免离开 Blender 的操作习惯。
- 不因精简而删除实际动作、发送同意、执行确认、取消、验证和回滚。
- 不把“未配置 AI”伪装成离线 AI 成功，也不自动填写凭据或更改联网许可。

## 验证

先补纯 Python 呈现测试，再接原生 UI；以界面记录器检查所有状态和设置折叠；回归已有事务、取消、过期计划与隐私测试。视觉检查限两轮，覆盖实际窄侧栏及浮窗，固定验证头像尺寸。未运行真实模型或未检查主题时如实记录。
