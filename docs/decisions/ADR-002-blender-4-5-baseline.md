# ADR 002 Blender 4 5 开发基线

状态：已接受

日期：2026-09-11

## 背景

原始开发规范选择 Blender 5.2 LTS 作为首个开发和评测版本，但当前可用环境为 Blender 4.5.12 LTS。如果等待另一个版本，Blender 适配层、扩展打包和安装流程将无法接受真实验证，而 M1 使用的 API 已存在于 4.5 LTS。

## 决策

Blender 4.5 LTS 成为最低支持版本和 M1 主开发基线。manifest 使用 `blender_version_min = "4.5.0"`。所有 M1 发布证据必须记录精确的 4.5 补丁版本。Blender 5.2 保留为后续兼容目标，只有单独验证通过后才能声明支持。

## 备选方案

不选择等待 Blender 5.2，因为这会让 Blender 代码与打包流程长期处于未测试状态。也不选择保留 5.2-only manifest、同时私下使用 4.5 脚本测试，因为这会让产品声明与真实开发环境不一致。

## 影响

项目可以立即在 LTS 版本上安装和验证，但代码不得依赖 4.5 之后才出现的 API。支持 4.5 可能限制后续部分界面或打包方案。未经独立测试，不推断兼容 5.2。

## 验证

使用 Blender 4.5.12 LTS 运行官方 validate/build，安装构建 ZIP，验证启用与禁用无异常，并连续运行 20 次 headless M1 集成测试且无非确定性失败。
