# ADR 011 参数化电路板外壳基础边界

状态：已接受；日期：2026-10-16。

## 背景

用户明确将下一阶段收缩为面向电子、机器人和竞赛项目的可打印外壳与安装件工具：根据真实器件尺寸生成可调参数的结构，检查装配和打印约束，再由用户确认后导出。该方向改变了原规范“不做 mesh 建模”的产品边界，必须先冻结一个可测试的小范围，不能直接让模型自由操作 Blender。

当前没有用户提供的真实电路板尺寸或实物打印结果。因此本阶段不能宣称完成真实装配验证，也不能先制作一个只靠外观看似正确的盒子。

## 决策

新增独立的“参数化打印件 P0”实验轨，不改写 0.6.3 场景编排语义。本轮只实现纯 Python 的外壳领域模型、确定性尺寸推导和打印规则检查，暂不连接 Blender UI 或修改场景。

P0 仅支持：

- 轴对齐矩形电路板；
- 以电路板左前下角为局部原点的圆形安装孔；
- 位于前、后、左、右侧壁的矩形接口开口；
- 矩形底座、固定柱和独立上盖；
- 壁厚、底厚、盖厚、板边间隙、板顶间隙、固定柱和接口间隙；
- FDM 最小壁厚、最小孔径和装配间隙检查。

领域尺寸统一使用毫米，不混入 Blender scene unit。生成结果必须明确给出外壳外部尺寸、内部尺寸、电路板位置、固定柱中心和接口开口尺寸。调整外壳间隙不得改变电路板安装孔之间的相对位置。

无效、非有限、越界或当前不支持的参数必须返回稳定错误；打印规则问题输出结构化 issue，不允许为了生成成功而静默夹值。真实网格生成进入后续 P1，届时对象创建、替换和删除必须先扩展 action schema、checkpoint、executor 和 verifier，不能从 UI 直接调用 `bpy`。

## 未采用

- 不从照片猜测电路板精确尺寸，因为没有标尺和公差依据。
- 不用 LLM 生成或执行任意 Blender Python，因为结果不可重复且无法可靠验证。
- 不在 P0 支持斜面、曲面电路板、非矩形接口、卡扣、热熔螺母、自动布线或切片器控制。
- 不把合成演示板称为真实器件，也不把几何规则通过称为实际打印通过。

## 代价

第一轮不会在 Blender 中出现可见盒子，也不能导出 STL；换来的是参数语义、边界和检查结果可以用纯 Python 稳定验证。以后接入 Blender 时需要增加对象创建事务和网格级验证，不能复用只保存 transform 的旧 checkpoint。

## 验证

- 精确验证外部、内部和总高度推导；
- 修改外壳间隙后，固定柱相对电路板的位置保持不变；
- 拒绝非有限、负数、孔位越界和接口越界；
- 验证接口开口按间隙扩张；
- 验证低于打印配置的壁厚、孔径和装配间隙产生结构化阻断项；
- 同一输入重复生成结果完全一致。
