# ADR 004 扩展明确移动与锁状态指令

状态：已接受

日期：2026-09-29

## 背景

0.2.0 只能把一个已有物体放到另一个物体表面。核心动作协议、执行器和验证器已经支持 `move`、`lock` 与 `unlock`，但用户无法从界面指令触发这些白名单动作，导致连续微调仍需返回 Blender 手工操作。

## 决策

0.3.0 在本地解析器中增加三类明确指令：按世界坐标左、右、前、后移动指定距离；锁定指定对象；解除锁定指定对象。距离支持米、厘米、毫米和对应英文缩写，并根据 Blender `unit_scale` 转换为场景单位。

每条指令仍只生成一个可确认 ActionPlan。移动锁定对象、零距离、未知单位、超出安全范围的距离、重复锁定或重复解锁均关闭失败。界面预览改为显示通用计划摘要，但执行仍必须经过 validator、transaction、executor 和 verifier。

## 备选方案

- 不采用“稍微移动”“往那边一点”等模糊距离，因为没有可验证的确定数值。
- 不采用视口或相机坐标，因为视角变化会改变同一句指令的结果。
- 不新增自由 Python 或直接修改 `bpy` 的解析捷径，避免绕过事务和验证层。

## 影响

用户可以在不离开指令流程的情况下完成摆放后的定量微调和锁状态管理。代价是必须写出对象名称、明确方向和距离；目前不支持上下移动、局部坐标、组合移动或对齐。

## 验证

纯 Python 测试覆盖单位换算、场景单位比例、锁定对象拒绝、零距离和未知单位。Blender 源码与隔离安装测试连续执行“摆放并锁定 → 左移 20 厘米 → 解除锁定”，并验证每次预览只读、确认后结果通过结构化校验。
