# 版本变更记录

## 未发布：参数化打印件 P0–P1

- 新增 `create_adapter_plate_mesh` 严格创建计划与全有或全无事务；用户确认前不修改 Blender。
- Blender 4.5 使用外轮廓和圆孔轮廓生成单一封闭转接板网格，孔真实贯穿，不再使用显示代理。
- 独立回读板尺寸、原点、圆角、孔数、孔中心、孔径、流形和连通分量；多余对象或既有场景变化
  也会失败回滚。
- Blender 4.5.12 实测 80 × 40 × 3 mm 四孔板为 328 顶点、504 面、单一连通流形；错误孔径
  和同事务额外对象注入都被拒绝并完整回滚。
- 新增 ADR 015、P1 中文说明、测试报告、渲染脚本和 11 项专项测试；全仓纯 Python 回归为
  135 项通过。
- 新增矩形转接板 P0 参数核心：支持矩形板、圆角、多组圆形贯穿孔规格，以及孔越界、圆角冲突、
  孔重叠和非法数值检查；结果可稳定序列化，但尚未生成 Blender 网格。
- 新增转接板保孔位修改：宽度或深度可以从左/右/中心、前/后/中心变化，通过板对象坐标补偿
  保持全部安装模式的世界孔位；部分模式保持在 P0 明确返回不支持。
- 新增 `needs_input`、`design_candidate`、`parameter_patch` 三类关闭字段 AI 候选协议；拒绝未知
  零件族、未知字段、任意 Python、可信字段注入和非有限数值，并在本地重新验证几何。
- 新增 ADR 014、中文 P0 说明、离线演示和 17 个行为测试；全仓纯 Python 回归为 124 项通过。
- 确认产品升级方向为“3D 打印零件助手”，提供按尺寸创建与按用途设计两个入口；记录需求澄清、
  引导测量、持续参数修改和打印反馈闭环。
- 冻结打印件 AI/BYOK 边界：复用现有用户自带 API 设置和隔离网络进程，AI 只输出严格的提问、
  设计候选或参数补丁，不直接执行 Python、创建网格或绕过本地事务。
- 新增轴对齐矩形电路板外壳的纯 Python 领域规格与确定性尺寸推导；全部尺寸统一使用毫米。
- 支持安装孔、四侧矩形接口、板边/板顶间隙、底座、上盖和固定柱参数；调整间隙不会改变孔位相对关系。
- 新增 FDM 最小壁厚、孔径和装配间隙阻断检查，以及无效数值、孔位越界、接口越界和固定柱材料不足的稳定错误。
- 新增严格的 `create_enclosure_preview` 创建计划、独立创建事务、后置尺寸验证和失败回滚；
  Blender 4.5 可生成底板、四面侧壁、线框上盖、电路板代理、固定柱和接口开口代理。
- 创建计划强制用户确认；同名外壳、重复计划、非法尺寸和不受支持几何在写入前拒绝。
- Blender 4.5.12 后台实测创建 12 个部件，并故意篡改回读尺寸验证完整回滚。
- P1 仍是装配预览，没有侧壁布尔开口、固定柱螺丝孔、流形检查、导出、AI 规划或真实打印声明；
  合成示例不冒充实物验证。
- 产品边界和创建事务要求记录于 ADR 011、ADR 012；打印意图与转接板语义记录于 ADR 013、ADR 014。

## 0.6.3

- 主界面改为阶段式布局：输入、AI 数据确认、计划确认、结果各显示一个主要动作；去掉大头像、重复对话和重复错误说明。
- AI 服务、精确控制、助手开关和用量收进默认收起的设置；返回助手不会丢失待确认计划。
- 缺少模型时给出明确设置入口，仍不联网；完整发送详情可展开，实际动作清单始终展示，两次用户确认不变。
- 连接成功后，设置内可展开查看服务返回的前 8 个模型名称，避免用户只能看到模型数量却无法填写名称。
- 中文按显示宽度换行，并结合侧栏宽度和系统缩放估算可用空间；浮窗从 560 缩为 420。
- 按用户指定更换透明头像，绘制 92 × 92 像素、点击半径 42 像素不变；去掉常驻外圈并减弱悬停填充。
- 保留图像来源和编辑提示；用户已确认拥有使用权，并明确要求随本版提交到公开仓库。
- 本机 LM Studio `qwen/qwen3-4b-2507` 安装版真实闭环通过：1 次请求、0 次修复，确认后执行和独立目标验证通过。
- 本机 `qwen3-vl-4b-instruct` 单独复验可连接但未返回合格结构化计划，场景未修改；0.6.3 不将其列为推荐规划模型。
- 模型响应结构异常时保留具体安全原因，不再一律误显示成“模型列表不兼容”。
- 未新增动作，未改变事务、独立验证、回滚、锁保护或网络同意策略。

## 0.6.2

- 新增显式输出格式：默认“通用 JSON”保持兼容，选择“LM Studio 结构化输出”发送严格 JSON Schema；界面、隔离工作进程和评测入口配置一致。
- Schema 关闭额外字段，限定本轮对象 ID、启用动作和参数边界；不自动降级成自由文本，不增加自动重试。
- 修复移动向量序列化：候选与执行计划的 `to_dict()` 统一输出 JSON 数组，避免内存直接复验因元组被严格解析器拒绝。没有放宽解析器。
- 澄清模型与执行器的职责：落面使用 `place_on`，精确坐标由本地计算；不要给被移动对象添加“保持原位”约束。
- 本机 LM Studio/Qwen 真实界面闭环和固定任务实测；保留初始 18/20 失败记录及澄清后 20/20 记录。该任务集只有 8 个 AI 正向任务，不能外推为产品通用准确率。
- 中文本机填写说明、ADR 009 和本版开发者验收报告同步更新。未新增动作或弱化验证器。

## 0.6.1

- 计划确认改为本地读取实际动作生成中文清单；显示对象、目标、区域、距离、世界坐标位移、米制位移、约束和当前锁状态。模型摘要仅供参考。
- AI 候选和执行前校验均拒绝 `unlock`，防止模型自行绕过锁定。明确的本地解锁指令仍可用。
- 新增 20 个公开合成任务，独立检查最终目标、允许变化对象、路由和正确拒绝；错误方向或额外移动不能靠“事务提交”冒充任务成功。
- 新增只读审查、人工候选回放、真实模型三种评测模式；默认不联网，真实模式默认 HTTP 总上限 2 次，修复请求计入同一上限。
- 新增 Blender 出厂启动隔离夹具评测入口；不会载入或保存用户 `.blend`。
- 回放与真实模型指标分离，预算耗尽的任务显式记录为跳过；报告不保存密钥、模型正文或私有资产。

## 0.6.0

- 新增 AI 结构化规划闭环：模糊指令可以调用用户配置的 OpenAI-compatible `/chat/completions` 服务生成候选计划。
- 保持本地解析器优先；可离线处理的明确指令不会发送给模型。
- AI 调用前新增“本轮发送数据”审查步骤；只有用户点击“同意并调用 AI”后才联网。
- 默认只发送当前指令、场景单位比例、动作 schema，以及最多 20 个相关可见对象的 ID、名称、类型、位置、尺寸和锁定状态。
- 模型只允许提出 `place_on`、`move`、`lock`、`unlock` 和 `preserve_transform`；任意 Python、未知字段、错误对象、重复 ID 和危险参数均关闭失败。
- 可信 `plan_id`、场景指纹、来源和确认要求全部由本地主进程生成，模型不能伪造。
- 候选输出在网络子进程和 Blender 主进程中各校验一次；无效 JSON 最多修复一次，第二次失败返回稳定错误。
- AI 计划必须先预览、再由用户确认；执行继续经过原有 validator、transaction、executor、verifier 和回滚链。
- 新增规划取消、超时、无效输出和场景过期拒绝；这些情况都不会产生可执行计划或修改场景。
- 显示 Provider、模型、输入/输出 Token、延迟、请求次数和修复次数；不估算费用。
- 新增上下文筛选、候选计划、模型适配、子进程和 Blender 端到端回归测试。

## 0.5.0

- 新增 Provider 中立契约，为后续 AI 规划隔离具体服务商。
- 新增 OpenAI-compatible `/models` 连接测试，支持远程 HTTPS 和本机 HTTP 服务。
- 新增“AI 服务连接”界面，可填写 API 地址、模型、临时 API Key 和超时，并显示连接、模型可见性、耗时与取消结果。
- API Key 仅保留在 `WindowManager` 会话属性或环境变量，不写入 `.blend`、普通首选项、命令行或日志。
- 网络调用在 Blender 自带 Python 的短生命周期子进程中执行，Key 通过标准输入传递，Blender 主线程使用定时器轮询。
- 拒绝带账户信息、查询参数或片段的 URL；远程 HTTP 关闭失败；拒绝重定向并限制响应大小。
- 尊重 Blender 的“允许联网访问”设置；无效配置、断网、超时、认证失败、限流、服务错误和取消均不会创建计划或修改场景。
- 0.5.0 只建立安全连接基础设施，尚未把场景或用户指令发送给模型，也尚未让 AI 生成 ActionPlan。

## 0.4.0

- 产品名更新为“场景领航员”，扩展名称不再包含平台名称。
- 3D 视图右下角新增原创二维助手形象；它是界面叠加层，不进入场景、渲染或导出。
- 点击助手形象可打开原生 Blender 浮动面板，也可继续从 `N → BSA` 进入。
- 原三步表单重构为中文对话式面板，保留精确控制作为可展开的备用入口。
- 新增待机、等待确认、工作、成功、错误五态交互状态机与中文状态反馈。
- 用户指令、计划摘要和执行验证结果形成最小对话闭环。
- 所有写操作仍经过 ActionPlan、事务、执行器和验证器；没有引入网络、API Key、模型调用或任意 Python 执行。

## 0.3.0

- 本地解析器新增世界坐标左、右、前、后定距移动。
- 支持米、厘米、毫米及 `m/cm/mm`，按 Blender 场景单位比例换算。
- 新增独立的“锁定对象”和“解除锁定对象”中文指令。
- 锁定对象的移动在预览前即被拒绝；零距离、未知单位和过大距离关闭失败。
- 预览面板改为展示通用计划摘要，不再假定每个计划都有源物体和目标表面。
- Blender 端到端测试覆盖“摆放并锁定 → 定距移动 → 解除锁定”的连续操作。

## 0.2.0

- 新增不访问网络的中文本地指令解析器。
- 支持“把 Lamp 放到 Desk 右侧”及显式锁定说法，并生成标准 ActionPlan。
- 未明确要求锁定时，不会擅自添加锁定动作。
- 对模糊指令、未知对象、同一源/目标和未支持的附加要求关闭失败。
- 指令输入仍经过预览、用户确认、事务执行、验证和回滚，不能跳过安全层。
- 保留 0.1.1 的手动选择入口作为可控备用流程。

## 0.1.1

- 将发布版本从 0.1.0 升级为 0.1.1，避免 Blender 继续识别为旧安装包。
- 面板、字段、按钮、提示和结果改为中文；由于 Blender 4.5 会把中文竖排分类显示为 `UNSUPPORTED`，侧栏入口使用稳定的 `BSA` 缩写。
- 界面改为“选择物体 → 生成预览 → 确认执行”三步流程。
- 对未选择物体、选择同一物体、过期预览、锁定对象和不支持几何提供中文说明。
- 生成预览后修改任一输入时，旧计划自动失效。
- 执行成功或失败后禁止重复提交同一份计划。
- 保留机器可读的结构化结果供测试使用，但不在普通用户面板中显示 JSON。

## 0.1.0

- 完成 M1 确定性摆放、计划预览、事务执行、结果验证、锁定保护和失败回滚。
