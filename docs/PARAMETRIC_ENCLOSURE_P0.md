# 参数化电路板外壳 P0

状态：领域核心已完成；P1 已接入 Blender 装配预览，但尚未接入正式用户界面。日期：2026-10-16。

## 这一阶段解决什么

P0 把“做一个电路板外壳”拆成可验证的毫米制参数，而不是让模型直接写脚本。输入包括电路板长宽高、安装孔、矩形接口、外壳壁厚、间隙、固定柱和上盖参数；输出包括外壳内外尺寸、电路板位置、固定柱中心和加入间隙后的接口开口。

同一输入必须得到完全相同的结果。调整板边间隙时，外壳尺寸和固定柱绝对位置随之变化，但固定柱相对电路板的孔位关系保持不变。

## 已支持

- 轴对齐矩形电路板；
- 圆形安装孔；
- 前、后、左、右侧壁的矩形接口；
- 分体式底座和上盖的尺寸推导；
- 壁厚、底厚、盖厚、板边间隙、板顶间隙、固定柱和接口间隙；
- FDM 最小壁厚、最小孔径和最小装配间隙检查；
- 非有限值、负数、孔位越界、接口越界和固定柱材料不足的稳定拒绝；
- JSON 兼容的确定性设计结果。

## P0 当前明确没有完成

- 没有在 Blender 中生成网格；
- 没有参数面板、自然语言解析或 AI 调用；
- 没有 STL/3MF 导出；
- 没有真实电路板、打印机或装配结果；
- 没有检查非流形、自相交、悬垂或切片参数。

合成示例只证明参数逻辑，不代表真实打印成功。P1 已按 ADR 012 增加白名单创建计划、创建型
checkpoint、executor 和 verifier，具体范围与限制见 `PARAMETRIC_ENCLOSURE_P1.md`；正式 UI、
可打印布尔网格和导出仍未完成。
