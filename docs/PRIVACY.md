# 隐私与 API Key 说明

状态：适用于 3D 打印零件助手 0.7.0 开发版  
日期：2026-10-16

## 什么时候会联网

插件只在以下两种明确操作后联网：

1. 用户点击“测试连接”：请求所填服务的 `GET /models`。
2. 本地解析器无法可靠理解指令，界面先展示“本轮发送数据”，用户随后点击“同意并调用 AI”：请求 `POST /chat/completions`。

仅输入文字、点击“解析并生成预览”或查看数据预览都不会调用 AI。用户可以点击“不发送”清除本轮待发送内容。

0.7.0 的“3D 打印零件”流程完全本地运行。“检查参数”和“确认并创建”都不会调用 AI，也不会
发送板件尺寸、孔位或场景数据。板件尺寸保存在 `.blend` 中；检查摘要、错误、结果和计划 ID
只保留在当前 Blender 会话。

保留的旧“场景领航员”按钮名为“生成计划”和“同意发送并生成计划”。设置、可用模型名称、
完整发送详情和用量的展开状态只存在于会话；展开不触发联网，默认精简不等于取消同意。完整
发送详情仍可查看，检查实际动作后还需要另一次“确认并执行”。头像只是本地界面资源，不属于
发给模型的场景摘要，不会进入渲染。

## AI 规划会发送什么

每次规划请求只发送：

- 当前这一条用户指令。
- Blender 场景单位比例。
- 当前允许模型提出的动作结构说明。
- 最多 20 个相关可见对象的摘要：稳定对象 ID、名称、类型、世界位置、世界尺寸和锁定状态。

如果指令中明确写出对象名称，只选择匹配对象；没有明确名称时，按稳定顺序选择最多 20 个可见对象。实际对象列表会在联网前显示给用户。

模型第一次返回无效 JSON 时，插件最多发送一次修复请求。修复请求会包含第一次模型输出的截断内容，因此一次用户操作最多可能产生两次模型请求。插件不进行无限重试。

0.6.2 的“LM Studio 结构化输出”额外使用正式候选 JSON Schema 约束返回格式；Schema 中的对象 ID 来自同一份已展示上下文，不新增资产数据，不自动切换服务或降级成自由文本。本机未启用认证时可以留空 Key，但环境变量中的 Key 仍会被读取；纯本机测试应清除旧变量。明文 HTTP 仅允许 `localhost/127.0.0.1/::1`，本机服务仍需要 Blender 允许联网和逐次用户同意。

## 默认不会发送什么

- 完整 `.blend` 文件。
- 网格顶点、面、UV、骨骼或几何节点内容。
- 材质、纹理、资产文件或渲染结果。
- 截图、视口图像或相机画面。
- 对象矩阵、包围盒、父子关系或完整场景历史。
- 以前的用户指令、计划或验证结果。
- API Key 本身作为模型输入内容。

0.6.0 没有“发送预览图”功能，也没有后台遥测。

## API Key 怎样保存

- 面板中输入的 Key 只放在当前 `WindowManager` 会话属性，并标记为不保存。
- 可选择从 `BSA_API_KEY` 或 `OPENAI_API_KEY` 环境变量读取。
- Key 不写入 `.blend`、插件普通首选项、项目文件或日志。
- Key 通过子进程标准输入传递，不放在系统进程命令行。
- Key 只用于 HTTP `Authorization` 请求头，不写入模型消息。
- 关闭 Blender 后，面板中输入的 Key 不会由插件恢复。

环境变量是否被操作系统、启动脚本或其他程序记录，不由本插件控制。共享电脑上不要把 Key 写入公开脚本，也不要在截图或录屏中展示它。

## 网络与地址限制

- 远程 API 地址必须使用 HTTPS。
- 只有 `localhost`、`127.0.0.1` 和 `::1` 可以使用 HTTP。
- 地址不能包含用户名、密码、查询参数或片段。
- 客户端拒绝重定向，并限制请求与响应大小。
- 插件尊重 Blender 的“允许联网访问”设置；关闭时不会发起请求。
- 网络任务运行在短生命周期子进程中，不能访问或修改 Blender 场景。

## 第三方服务责任

插件不会替用户选择服务商。服务商可能按照自己的条款记录来源 IP、请求时间、账户、模型、指令和对象摘要，也可能用这些数据做保留、审核或训练。使用真实项目资产前，应阅读所选服务商的隐私政策、数据保留条款和费用说明。

界面显示的 Token 数量来自服务端返回值；服务端没有提供时就显示不可用。0.6.0 不估算费用，也不承诺不同 OpenAI-compatible 服务拥有相同的数据处理方式。

## 开发者固定任务评测

评测脚本不读取正在编辑的用户场景。默认 `review` 只生成公开合成夹具的发送数据报告；`replay` 只回放人工固定候选，两者均不联网。只有显式选择 `live` 并提供地址、模型后才可能发请求，默认最多 2 次 HTTP，修复也占用上限。Key 从环境变量读取，不接受命令行 Key。

真实模型模式发送任务指令、合成对象摘要和动作协议；自动确认仅用于脚本自己建立的一次性夹具，不改变插件的用户确认要求。Blender 入口拒绝加载用户文件，且需允许联网。结果记录任务 ID、判定、用量和耗时，不保存 Key、模型响应正文或私有资产。失败请求可能已经产生费用；服务端未返回用量时记录为未知，不能当作零 Token。
