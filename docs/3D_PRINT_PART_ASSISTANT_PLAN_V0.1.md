# 3D 打印零件助手方案 V0.1

日期：2026-10-18  
状态：产品方向已确认；确定性外壳 P0–P1、矩形转接板参数 P0、真实网格 P1、本地创建界面
P2 和 AI 零件意图候选协议已实现。转接板尚未接入真实 AI 请求。

## 1. 产品解决什么问题

首版面向需要定制小零件、但不熟悉建模的个人和项目团队。典型任务包括固定件、支架、
连接件、转接件和日常打印配件。

产品连接三个连续问题：

1. **知道要做什么，也知道尺寸，但不会建模。** 软件把明确参数直接转换成可检查的模型。
2. **只知道用途，不知道结构怎样设计。** AI 帮助拆解安装关系、指出必须测量的尺寸，并提出
   少量受支持的结构方案。
3. **第一版需要继续修改。** 用户通过参数修改外形，同时保留孔位等已经确认的关系，并能查看
   本次变化和撤销。

产品不是通用 text-to-3D，也不让模型自由执行 Blender Python。竞争力来自器件数据、参数关系、
制造规则、装配验证和真实打印反馈。

## 2. 两个入口

### 2.1 按尺寸创建

适合用户已经知道关键尺寸的情况，例如：

> 做一个 80 × 40 × 3 mm 的转接板，左侧两个孔间距 24 mm，右侧两个孔间距 30 mm。

系统提取并展示参数；缺少阻断性尺寸时只询问缺少项。用户确认后，由本地参数引擎生成，
不需要调用 AI 也能使用。

### 2.2 按用途设计

适合用户只知道安装目标的情况，例如：

> 我想把这个设备固定到现有支架上，但两边孔的位置不一样，而且最好能拆下来。

AI 先判断哪些信息会影响当前设计，例如两侧孔数和孔位、可用空间、突出部位、安装方向和
拆卸方式。它只提影响当前候选方案的问题，不重复询问已经确认的事实。

软件随后展示简单示意图和一个受支持的结构候选，让用户填写或确认关键尺寸。照片可以帮助
表达外形、位置和用途，但关键配合尺寸仍必须由用户测量或来自可靠尺寸资料；不能从单张照片
伪造精确毫米值。

两个入口最终进入同一套参数模型、事务、验证和导出流程。用户不需要在开始时永久选择入口；
有完整尺寸就直接生成，过程中缺信息再补充。

## 3. 首版操作闭环

### 第一步：理解需求

- 保存已确认的用途、限制和尺寸；
- 标出“已确认”“使用默认值预览”“必须补充”三种信息状态；
- 一次优先询问最影响当前结构的少量问题；
- 明确说明 AI 建议与本地已验证规则的区别。

### 第二步：引导测量并生成模型

- 用示意图指出从哪里量到哪里；
- 用户确认孔位、外形、安装空间和必要间隙；
- 在 Blender 中生成真实参数化零件；
- 孔必须真实贯通，可分开的部件能够独立查看；
- 模型旁显示关键尺寸，孔可查看直径、位置和参考对象。

### 第三步：继续修改

例如：

> 这块板加长 10 mm，设备安装孔的位置保持不变。

系统把“外形长度”和“设备安装孔关系”作为不同参数处理：只修改被授权字段，保留明确锁定的
安装关系，检查孔到边缘距离等规则，展示参数差异，并允许撤销到上一版。

### 第四步：根据试装结果修正

记录设计孔径、实测孔径、打印材料、打印方向、打印机/切片设置和试装现象。软件区分：

- 设计尺寸错误；
- 装配间隙不足；
- 打印过程产生的尺寸偏差。

自动补偿必须基于用户自己的打印记录或明确配置，不能把某一台打印机的经验当成通用规则。

## 4. AI 在产品中的职责

AI 只允许产生三类候选结果：

1. `needs_input`：列出缺少的关键测量、原因和测量方法；
2. `design_candidate`：为某个已支持零件族给出严格参数候选和假设；
3. `parameter_patch`：修改允许变化的参数，并列出必须保持的关系。

所有结果必须经过本地 Schema 校验、范围检查和用户确认。AI 不得：

- 输出或执行任意 Python / `bpy`；
- 直接创建、删除或修改 Blender 对象；
- 绕过零件族的几何约束、检查点和验证器；
- 把估计尺寸冒充用户测量值；
- 在没有真实证据时声称模型可以打印或装配成功。

## 5. 用户自带 API（BYOK）

插件复用现有“设置 → AI 服务”，不再制造第二套密钥表单：

| 设置项 | 作用 |
|---|---|
| 服务地址 | OpenAI-compatible API 根地址；远程必须 HTTPS，本机允许回环 HTTP |
| 模型名称 | 用户选择的规划模型 |
| 临时密钥 | 密码输入框，只保留在本次 Blender 会话 |
| 输出格式 | 通用 JSON 或严格 JSON Schema |
| 超时 | 单次连接或规划请求的最长等待时间 |
| 测试连接 | 只检查连接和模型列表，不发送零件、照片或用户指令 |

也可以通过 `BSA_API_KEY` 或 `OPENAI_API_KEY` 环境变量提供密钥。密钥不写入 `.blend`、日志、
命令行或 Git。AI 功能可选；“按尺寸创建”和后续参数调整的本地确定性功能不能因为没有 API
而被锁死。

每次真正调用前必须显示本轮发送内容，包括用户指令、已确认尺寸、候选零件族、打印配置摘要
和是否包含图片。默认不发送 `.blend`、完整网格、历史项目或未选择的图片。

## 6. 技术流程

```text
用户输入 / 参数表 / 可选照片
          ↓
本地确定是否已有足够参数
     ↓否                    ↓是
AI 候选问题/方案          直接进入本地计划
     ↓
严格零件意图 Schema
          ↓
本地参数校验 + 用户确认
          ↓
参数化零件计划
          ↓
创建事务 → Blender 执行器 → 尺寸/关系/网格验证
          ↓
版本差异 / 撤销 / 导出 / 打印反馈
```

AI Provider 可以更换，本地零件协议、执行器和验证器不能随模型改变。

## 7. 首版支持范围与顺序

1. **电路板外壳**：已有 P0 参数推导与 P1 装配预览；下一步完成真实开孔、螺丝孔和流形检查。
2. **矩形转接板**：参数核心支持多组圆孔、板外形、厚度、轮廓检查和外形修改时的孔位保持；
   Blender P1 已实现单一封闭网格、真实贯穿孔、创建事务、独立回读和失败回滚。
3. **统一参数 UI**：按尺寸创建、按用途设计、设计候选、修改差异和验证结果。
4. **AI 零件意图接入**：三类严格候选 Schema 和本地解析已完成；下一步复用现有 BYOK 配置和
   隔离网络进程发起真实请求，仍不允许模型直接操作场景。
5. **导出与实物验证**：通过网格门禁后再支持 STL/3MF，并记录至少一组真实打印装配结果。

首版不承诺任意零件、自动从照片恢复精确尺寸、自动切片、打印机控制或无需测量的一键生成。

## 8. 验收指标

- 无 API 时，完整尺寸任务仍能本地完成；
- AI 调用失败、取消、超时或输出非法时，Blender 场景零修改；
- AI 不能提出未在 Schema 中的结构或执行代码；
- 用户确认前不创建零件；
- 修改外形时，声明保持的孔位关系在容差内不变；
- 后置校验失败能恢复上一版本；
- 正式声称“可打印”前通过流形、尺寸和导出检查，并保留真实打印证据。
