## 失败、原因与修复证据

- 旧格式 `json_object` 被当前 LM Studio 拒绝，HTTP 400 明确要求 `json_schema` 或 `text`。采用显式 Schema 模式，不自动降级。
- 第一条试跑暴露移动向量 `to_dict()` 仍为元组，候选直接复验被拒绝。先增加失败回归，再统一序列化为数组。
- 模型曾用 `move` 自行估算落面坐标；事务提交不代表用户目标正确。提示词明确落面必须使用 `place_on`，准确位置由本地执行器计算。
- 第一轮全量中的 `ai_03/ai_08` 对 Lamp 同时要求移动和保持原位，触发 `POSTCONDITION_FAILED`。场景完整回滚；独立内存复诊再次出现同类约束，并捕获失败检查为 `preserve_transform`，实际位移分别为 1.0 和 1.78。
- 澄清保持原位不是保持网格形状、约束应指向用户要求不动的对象后，第二轮全量通过。没有删除失败报告、修改预期目标或放宽验证器。提示词仍不是可靠的通用意图验证器。
