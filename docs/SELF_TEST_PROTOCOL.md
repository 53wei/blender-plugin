# 3D 打印零件助手个人测试规范

## 目的

当你暂时是唯一测试者时，用这份规范形成可信的工程证据。个人测试不能替代后续外部用户观察，但可以先证明功能、错误处理和回滚是否可靠。判断依据是结构化结果，不是“画面看起来差不多”。

## 每次测试先记录

- 日期与精确 Blender 版本
- 扩展版本或 ZIP 文件名
- 操作系统
- `.blend` 场景名称，以及是否包含真实导入资产
- 非默认单位、缩放、旋转或父子关系

0.9.0 手动测试必须确认 3D 视图右下角显示可点击的助手形象，点击后打开“3D 打印零件”流程；
侧栏标签仍为 `BSA`。需求、发送确认、补充测量、参数确认和结果必须分阶段显示中文，不展示内部
JSON。整理需求和检查参数前后对象数量必须不变；只有“确认并创建”可以通过事务写入场景。
Blender 4.5 的竖排侧栏分类不能可靠显示中文，因此备用入口使用 ASCII 缩写。

原 0.6.x 场景领航员仍在 `N → BSA` 的折叠面板中。展开其“AI 服务连接”后，还必须确认 Key
字段被遮盖、连接测试和 AI 规划均可取消、错误不会生成计划或修改场景。模糊指令必须先出现
“本轮发送数据”，用户同意前不得产生网络请求；AI 计划出现后仍需第二次确认才能执行。

## 自动化门禁

```powershell
$Blender = "blender" # 未加入 PATH 时替换为 blender.exe 的完整路径
& $Blender --command extension validate
& $Blender --command extension build --output-dir dist
& $Blender --background --factory-startup --python-exit-code 1 --python tests/integration/run_m1_suite.py
& $Blender --background --factory-startup --online-mode --python-exit-code 1 --python tests/integration/run_provider_ui_suite.py
.\scripts\run_adapter_plate_mesh_tests.ps1 -Blender $Blender
.\scripts\run_adapter_plate_ui_tests.ps1 -Blender $Blender
```

接受 M1 前，headless 测试必须连续运行 20 次。保留命令输出和生成的 JSON。任何偶发失败都会阻止该关卡通过。

## 手动测试案例

每个案例使用测试 `.blend` 的新副本。

| 编号 | 操作 | 预期证据 |
|---|---|---|
| M01 | 把 Lamp 放到 Desk 中央 | 预览显示两个对象；提交成功；上下表面间隙验证通过 |
| M02 | 把 Lamp 放到 Desk 右侧 | 右侧检查通过，Desk 的变换保持不变 |
| M03 | 生成预览后手工移动 Desk，再确认 | 返回 `PLAN_STALE`，Lamp 不变 |
| M04 | 锁定 Desk 后再尝试移动 Desk | 返回 `OBJECT_LOCKED`，Desk 不变 |
| M05 | 使用比 Desk 更宽的源物体 | 返回 `SPATIAL_UNSUPPORTED_GEOMETRY`，场景不变 |
| M06 | 绕世界 X 或 Y 倾斜 Desk 后尝试摆放 | 返回不支持的几何错误，场景不变 |
| M07 | 分别使用 0 和正数表面间隙 | 两次实际间隙都在容差内 |
| M08 | 启用、禁用并重新启用扩展 | 控制台无异常，不出现重复注册 |
| M09 | 生成预览后修改摆放区域 | 旧预览立即失效，确认按钮禁用 |
| M10 | 安装 0.6.2 替换旧版 | 扩展页显示 0.6.2，视图右下角出现助手，面板标题为“场景领航员” |
| M11 | 输入“把 Lamp 放到 Desk 右侧” | 生成本地计划，预览阶段 Lamp 不移动 |
| M12 | 指令未要求锁定 | 计划中不包含 lock 动作 |
| M13 | 指令中写“并锁定 Desk” | 计划中包含 lock，确认后 Desk 锁定 |
| M14 | 输入“帮我布置得更好看” | 先进入 AI 数据确认，不联网、不改场景 |
| M15 | 指令引用不存在的对象 | 显示找不到对象，场景不变 |
| M16 | 输入“Lamp 向左移动 20 厘米”并预览 | 生成 move 计划，Lamp 尚未移动 |
| M17 | 确认 M16 | Lamp 沿世界坐标负 X 移动 0.2 米，验证通过 |
| M18 | 锁定 Lamp 后再次要求移动 | 预览前明确拒绝，Lamp 不变 |
| M19 | 输入“解除锁定 Desk” | 生成 unlock 计划，确认后 Desk 可再次选择 |
| M20 | 连续执行摆放、移动、解除锁定 | 每一步独立预览和确认，全部结构化验证通过 |
| M21 | 点击视图右下角助手形象 | 打开中文输入面板，助手不是场景对象且不会出现在渲染或导出中 |
| M22 | 输入指令并完成一次执行 | 助手依次显示等待确认、工作和成功状态，计划确认前场景不变 |
| M23 | 关闭“在视图中显示助手” | 实体入口隐藏，仍可从 `N → BSA` 打开面板并重新启用 |
| M24 | 填写远程 HTTP 地址并测试 | 联网前拒绝，提示远程服务必须使用 HTTPS，场景不变 |
| M25 | Blender 禁止联网时测试有效 HTTPS 地址 | 提示启用联网访问，不启动子进程，场景不变 |
| M26 | 使用本机模拟服务测试连接 | 显示连接成功、模型数量、模型可见性和耗时，不生成计划 |
| M27 | 测试一个延迟响应并立即取消 | 子进程停止，界面显示已取消，Blender 保持可操作 |
| M28 | 会话字段输入唯一测试 Key 后保存 `.blend` | 在文件字节中找不到该 Key；重新打开后字段为空 |
| M29 | 模拟 401、429、5xx、超时和错误 JSON | 分别显示稳定中文错误，场景、计划和结果均不改变 |
| M30 | 检查系统进程参数和插件日志 | 找不到 API Key、Authorization 或响应正文 |
| M31 | 输入“重新安排 Lamp 和 Desk，让画面更紧凑” | 显示本轮指令、单位和两个对象摘要；未同意前服务端请求数为 0 |
| M32 | 在 M31 点击“不发送” | 待发送数据被清除，返回待机，场景不变 |
| M33 | 在 M31 点击“同意并调用 AI” | 进入 AI 规划状态；主界面可操作；场景仍不变 |
| M34 | 模型返回合法白名单候选计划 | 显示来源为 AI 的计划摘要和 Token/延迟；确认前场景不变 |
| M35 | 确认 M34 的 AI 计划 | 计划经事务执行并通过验证；未授权变化为 0 |
| M36 | AI 规划中点击取消 | 子进程终止，不创建计划，场景不变 |
| M37 | AI 规划等待期间手工移动相关对象 | 返回 `PLAN_STALE`，旧 AI 计划不可执行，用户自己的移动保留 |
| M38 | 模型连续两次返回无效 JSON 或未知动作 | 返回 `PROVIDER_OUTPUT_INVALID`，最多发出两次请求，场景不变 |
| M39 | 检查发给模拟服务的请求正文 | 只含已预览字段；不含 Key、矩阵、网格、材质、纹理、截图或历史 |
| M40 | AI 返回任意 Python、错误对象 ID 或超限位移 | 主进程关闭失败，不生成可执行计划 |
| M41 | 模型摘要说不移动，但真实动作要求摆放 | 本地预览显示实际物体、目标和区域，摘要仅列为建议 |
| M42 | 模型要求解锁后移动锁定对象 | 拒绝 AI 解锁，场景不变；明确本地解锁仍可单独确认 |
| M43 | 固定评测回放错误方向或额外移动 | 即使事务提交，独立用户任务判定仍失败 |
| M44 | 真实评测达到 HTTP 上限 | 下一请求在联网前被阻止，剩余任务标为跳过，不冒充全量成功 |
| M45 | LM Studio 选择“结构化输出”，使用本机聊天模型 | 工作进程发送严格 JSON Schema，额外字段仍被拒绝；确认前只读，确认后独立目标通过 |
| M46 | 候选 move 直接 `to_dict()` 后再次解析，不先做 JSON 字符串转换 | 位移是数组，严格二次解析通过；解析器不接受元组或额外字段 |
| M47 | 模型要求移动 Lamp 又约束 Lamp 保持原位 | 验证失败并回滚，不能为了成功删约束或放宽验证器；失败记录保留 |
| P01 | 空白工程点击右下角助手 | 打开“3D 打印零件”，首屏显示需求输入、“整理需求”和“直接填写尺寸” |
| P02 | 使用默认 80 × 40 × 3 mm 参数检查 | 显示两组四孔摘要；对象数量、变换和网络请求均不变 |
| P03 | 检查后修改任一尺寸 | 旧摘要立即失效，必须重新检查后才能创建 |
| P04 | 将孔中心移到板外后检查 | 显示具体几何错误并展开孔位参数；场景不变 |
| P05 | 确认默认设计 | 创建一个单一封闭流形网格和四个真实贯穿孔，6 项验证全部通过 |
| P06 | 使用重复零件编号再次创建 | 创建前拒绝，不产生第二个对象 |
| P07 | 成功页查看说明 | 明确写出尚未完成切片、实物打印和试装验证 |
| P08 | 输入模糊用途并点击“整理需求” | 进入发送数据确认；服务端请求数仍为 0，场景不变 |
| P09 | 检查打印件发送预览 | 只含当前需求、既有测量问题和本轮回答；不含场景、网格、图片、默认尺寸或 Key |
| P10 | AI 返回 `needs_input` | 显示具体测量项、毫米单位和原因；用户可以填写补充信息 |
| P11 | 补充测量后继续 | 再次出现发送确认；未点击同意前没有第二次请求 |
| P12 | AI 返回受支持 `design_candidate` | 转为可编辑毫米参数，本地几何检查通过；场景仍不变 |
| P13 | AI 返回斜向孔、未知模式或任意 Python | 明确拒绝为不支持或无效候选，不近似转换，不修改场景 |
| P14 | 确认 P12 的候选 | 仅通过创建事务生成四孔流形网格，实际网格验证通过 |
| P15 | 创建成功后点击“继续修改这个零件” | 读取插件保存的当前设计，进入独立修改页，场景不变 |
| P16 | 输入“板加宽 10 毫米，右边不动”并整理修改 | 联网前显示修改指令和当前参数设计；不发送网格、其他对象或图片 |
| P17 | AI 返回宽度 `parameter_patch` | 本地显示板宽 80 → 90 mm、板深不变、原点补偿和孔世界位置不变；场景仍不变 |
| P18 | 不用 AI，展开“精确填写新尺寸”并设为板宽 90 mm、固定右边 | 产生与 P17 相同的只读差异，全程不联网 |
| P19 | 确认 P17 或 P18 | 原对象换入新封闭流形网格，尺寸为 90 × 40 × 3 mm，四孔世界位置和其他对象不变 |
| P20 | 在 P19 后点击“撤销本次修改” | 通过反向事务恢复 80 × 40 × 3 mm，四孔与非目标对象仍通过验证 |
| P21 | 在差异确认后手工改板或修改元数据，再确认 | 返回过期或不支持错误，不覆盖用户修改，不动其他对象 |

M45 的真实模型自测需记录模型名、输出格式和请求次数；通用模式模拟服务通过不代表 LM Studio 实测通过。插件填写示例见 `README.md`，自动化入口和实际两轮结果见 `MODEL_EVALUATION.md`。

## 单次记录模板

```text
案例编号：
场景文件：
预期结果：
实际结果：
状态：通过或失败
错误码：
耗时：
意外变化的物体：
截图或录像：
备注：
```

修复后不要删除失败记录。为真实 bug 新增回归测试，并把失败记录关联到修复。好的作品案例会展示至少一个真实失败、原因和修复后的重复验证。

## M1 退出条件

- Blender 4.5.12 LTS 的官方 manifest 校验和构建通过。
- headless M1 测试连续 20 次通过。
- 八个手动案例在方块夹具上通过，至少三个案例在真实导入资产上通过。
- 任何失败都不会留下半执行状态。
- 每个发现的 bug 都有可复现案例和回归测试。

在找到外部测试者前，请把这些结果称为“开发者测试”，不要称为“用户验证”。
