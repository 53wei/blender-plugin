# 0.6.3 简洁界面与本地模型验收

日期：2026-10-16。环境：Windows，Blender 4.5.12 LTS。范围：M2 内呈现改版与真实本地模型复验，不新增场景动作。

## 交付内容

主屏只突出当前阶段、输入和一个主要动作。AI 服务、精确控制、用量与头像开关进入设置；返回助手保留待确认计划。去掉重复对话、大头像和重复错误，保留完整发送详情、实际动作及保护约束、两次独立确认、取消和验证。

用户指定的第三张角色图经内置图像编辑工具处理为透明头像。绘制保持 92×92 像素，点击半径 42，位置不变；浮窗为 420 逻辑宽度，实际像素宽度受系统 UI 缩放影响。来源和编辑提示见 `bsa/assets/scene_pilot_idle.png.provenance.json`。

## 本轮运行结果

- 86 项 Python 单元测试通过，含 8 项新增呈现测试。中文换行不丢内容、窄宽度/缩放的列数估算、阶段文案、缺少模型、远程 HTTP 拒绝和模型响应具体错误通过。
- 源码和隔离 ZIP 安装版的简洁 UI 记录器通过：主屏不带连接表单和大头像；旧工程精确控制展开状态不挤占主屏；错误只显示一次；实际计划可见；设置不丢计划；缺模型可恢复；完整数据可展开；取消可达；绘制不改变对象变换。
- 模型列表回归先因列表缺失失败，修复后通过。模型名称只在连接成功且有结果的设置中可展开，默认收起、不联网，展开状态不保存。
- 源码及安装版回环模拟 API Schema 闭环通过：发送确认、只读计划、确认后执行验证、取消只读、过期结果拒绝、实际动作预览。模拟服务不代表真实模型效果。
- 隔离安装版连接本机 LM Studio `qwen/qwen3-4b-2507`，使用 `json_schema` 完成真实闭环：发送数据确认、只读计划、确认执行和独立目标验证通过；1 次请求、0 次修复，输入 628 Token、输出 92 Token，最终安装包复验的模型规划闭环用时约 1.83 秒。
- `qwen3-vl-4b-instruct` 在 `http://127.0.0.1:1234/v1` 做了单独的安装版完整复验：服务可连接，但该模型没有返回本插件可接受的结构化计划，流程安全失败且场景未修改。因此它在 0.6.3 中只算实验性、不作为推荐规划模型。随后精确加载 Qwen3 文本模型并通过。由此补充错误文案回归：规划响应异常显示具体安全原因，不再误称模型列表不兼容。
- 源码离线 UI 及安装版离线回归通过：本地摆放、移动、解锁、头像注册、会话密钥不写入探测工程、禁止联网时正确拒绝、发送审查只读。
- 扩展清单校验和 ZIP 构建通过；隔离安装根目录为 `.blender_test_user_0_6_3`。

## 未验证与风险

- 真实模型只验证了 1 个公开合成场景任务，不能外推为任意指令、任意资产或通用构图准确率。
- `qwen3-vl-4b-instruct` 虽可通过同一 OpenAI-compatible 地址访问，但本轮无法满足严格结构化计划协议；连接成功不等于规划兼容。
- 亮色主题、其他 DPI、实际更窄侧栏、长动作清单和展开完整数据后的浮窗尚未人工实测。纯函数换行测试不等于这些布局已验收。
- 用户已确认拥有角色图使用权并要求公开提交；项目保留来源记录。图片没有单独提供许可证文本，代码 GPL 不能替代图片授权说明。
- 安装新包不会热替换已运行的旧窗口；新开专用演示窗口使用新包。

## 操作方式

点击右下角角色，或在 3D 视图按 N → BSA。演示可输入“把 Lamp 放到 Desk 右侧”→“生成计划”→核对动作→“确认并执行”。这是本地确定性示例，不需要 API。模糊要求需要用户自己的模型服务：在设置填写服务地址和模型，测试连接后可展开名称；发送和执行仍分别由用户确认。
