# 矩形转接板 P4：创建后继续修改

状态：开发者验证完成  
日期：2026-10-19  
适用版本：0.9.0

## 用户可以做什么

用户创建矩形四孔转接板后，可以点击“继续修改这个零件”，然后使用两种入口：

1. 输入修改要求，例如“板加宽 10 毫米，右边不动”，由用户自己配置的 AI 生成受限参数补丁。
2. 展开“不用 AI，精确填写新尺寸”，直接填写新板宽或板深，并选择左/右/中心或前/后/中心哪一侧保持不动。

两种入口都进入同一个本地差异页。差异页显示前后尺寸、原点补偿和孔位保持结果；点击“确认并更新”前不修改 Blender 场景。

## 修改为什么是可验证的

更新不是删除旧对象后重建，也不是让 AI 执行 Python。插件会：

1. 读取对象上由创建事务保存的可信参数；
2. 确认当前实际网格仍与该参数一致；
3. 根据固定边计算新外形和对象原点补偿；
4. 在事务检查点中保留旧网格和其他对象状态；
5. 换入新网格，再从 Blender 实际数据回读尺寸、圆角、贯穿孔、流形和连通分量；
6. 验证四个孔的世界位置和孔径不变，且非目标对象不变；
7. 任一步失败恢复旧网格，并再次验证恢复结果。

成功页的“撤销本次修改”会构造反向更新计划，仍经过同一事务和验证器。当前只承诺一步撤销，不是无限版本历史。

## AI 和数据边界

修改请求会在联网前显示给用户。同意后只发送：本轮修改指令、需要时的测量问题/答案、当前转接板参数和严格 JSON Schema。不发送网格、场景其他对象、截图、纹理、历史项目或 API Key。

AI 只能选择新宽度/深度和固定边，无权创建网格、设置确认标志、改孔位或绕过本地验证。

## 当前明确不支持

- 修改厚度、圆角、孔径、孔距、孔数或部分孔位；
- 沉孔、螺纹、加强筋、复杂曲面和任意零件族；
- 安全修改用户手工建模、旧版本没有可信参数元数据的网格；
- STL/3MF 导出、切片、打印机配置或“已验证可打印”声明。
